# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Report them privately through GitHub's Private vulnerability reporting:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Fill in the form and submit it.

If you cannot use GitHub, please use the contact form on our website: <https://cdef-inc.com/jp_contactform/> (write "Vulnerability report: " in the subject).

Please include as much of the following as you can:

* The affected repository, branch, or version (commit hash if possible)
* A description of the vulnerability and its potential impact
* Steps to reproduce, or a proof of concept
* Any known workaround or suggested fix

## What to Expect

* We will acknowledge your report within 7 business days.
* We will assess the report, and keep you informed of our progress and our decision.
* When a fix is ready, we will publish a GitHub Security Advisory for this repository. We are glad to credit you in the advisory unless you prefer to remain anonymous.
* Please give us a reasonable time to address the issue before disclosing it publicly.

## Scope

This policy covers the code that CDEF, Inc. maintains in this repository.

## Open Source License Inquiries

For questions about the open source licenses of the software in this repository, please use the same contact form: <https://cdef-inc.com/jp_contactform/>

## 脆弱性の報告（日本語）

脆弱性は、公開の Issue・Discussion・Pull Request では報告しないでください。
GitHub の Private vulnerability reporting（非公開の脆弱性報告）でご報告ください。

1. このリポジトリの **Security** タブを開く
2. **Report a vulnerability** を押す
3. フォームに記入して送信する

GitHub を利用できない場合は、当社 Web サイトのお問い合わせフォーム（<https://cdef-inc.com/jp_contactform/>）をご利用ください。件名に「脆弱性の報告: リポジトリ名」とお書きください。

* 受領した旨を 7営業日以内 にお知らせします
* 内容を評価し、進み具合と対応の判断をお知らせします
* 修正の準備ができたら、このリポジトリの GitHub Security Advisory で公表します。ご希望があれば、報告者としてお名前を記載します
* 公表の前に、対応のための相応の期間をいただけますようお願いします

このリポジトリが他のプロジェクトの fork である場合、上流のコードの脆弱性は上流のプロジェクトにご報告ください。当社にご報告いただくのは、当社が加えた変更に固有のものに限ります。

OSS のライセンスに関するお問い合わせも、上記のお問い合わせフォームで受け付けます。
